# 大三元・大四喜・四槓子のパオ — Issue #39、2026-11-03

## 対応状況

Issue #39の本文をGitHubから再取得し、Issue #19の確定仕様と設計記録、Issue #37のGameRules v5基盤、およびmainの既存実装を照合して実装しました。Issue #39はOpenのままです。ユーザー本人によるiPhone Safari実機確認はまだ報告されていません。

## 実装内容と仕様対応

- `GameRules` v5の既存`pao`値を再利用しました。初期値OFF、旧形式の読込時OFF、ルール設定の保存・復元、オフライン新規対局、オンライン作成時のホスト正本、対局中のルール確認に反映しました。
- 責任対象は大三元・大四喜・四槓子だけです。大三元の3種類目、大四喜の4種類目のポン／大明槓、および手牌本人の4つ目の槓が大明槓として正式に成立した時点で記録します。加槓・暗槓では新しい責任者を記録せず、既存責任者も変更しません。
- 責任情報は役満ごとの対局状態と成立順として保持し、オンラインWorker snapshotとJSON保存・復元にも載せました。オンラインの打牌・鳴き・和了処理はWorkerの共通ゲーム関数が確定し、クライアントから責任者や支払額を指定しても採用しません。
- 和了結果は役満ID・倍率・責任者・役満ごとのpayer別負担額を保持します。責任対象分だけをツモ全額／ロン折半（責任者と放銃者が同一なら全額）とし、複合する対象外役満は通常精算します。大四喜の2倍設定は2倍分すべてを責任払いにします。
- 供託は既存どおり1回だけ和了者へ移し、ロン本場は放銃者、ツモ本場は責任払い対象がある場合に責任者へ1和了分を加算します。支払者が重なる場合は席ごとに集約し、点棒と供託の総量を検査します。
- オフライン・オンラインの「局の結果」に役満別の責任者、通常払い／責任払い、payer別点数を折りたたみ表示します。既存の役満合計表示、通常の本場・供託表示を維持します。

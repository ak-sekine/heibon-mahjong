## 後付け禁止の仕様調査と未確定点

調査日: 2026-11-01。

- 日本プロ麻雀連盟の用語辞典は、後付けを「役のない手で仕掛けて、後から役をつけること」と説明し、アリアリを喰いタン・後付けありとして説明しています。[日本プロ麻雀連盟・初級／麻雀用語辞典](https://www.ma-jan.or.jp/class_1/1552.html)
- 雀カクの用語解説は、役がまだない段階のチー・ポンから役牌を後でポンする例と、複数待ちの片和了を別ケースとして説明しています。後付けありでも役のない待ち牌では和了できません。[雀カク・後付け](https://jankaku.com/study/glossary/atozuke)
- 麻雀ローカルルールWikiは、「後付け無し」と「完全先付け」を使い分ける場合があり、喰いタンの有無とも独立に扱えること、第一副露の順序や片和了の扱いに複数例があることを記載しています。[麻雀ローカルルールWiki・完全先付け](https://w.atwiki.jp/mahjlocal/pages/108.html)
- 麻雀豆腐の解説も完全先付けに統一ルールがないとし、第一副露での役確定と片和了禁止等の条件を含む例を示しています。[麻雀豆腐・後付け／先付け](https://majandofu.com/atoduke)

| ケース | 現行エンジン | 未決定の後付け禁止ルールへの影響 |
| --- | --- | --- |
| 役が確定していない状態で最初の副露 | チー・ポン候補を提示可能。和了時に役があるかを判定 | この鳴きを禁じるか要判断 |
| 最初の副露で役が確定 | 現在の役候補を使う | 「先に役が確定」の判定主体・時点が必要 |
| 役牌ポンで役が確定 | その刻子の役牌を和了候補へ加算 | それ以前の副露の有無・順序を覚える必要がある |
| 役牌を後からポンして役が成立 | 現状は役牌が完成形に含まれれば有効 | 禁止するなら副露履歴と順序の検査が必要 |
| 片和了の待ち | 和了牌ごとの候補を個別判定し、役なし牌はロン／ツモ不可 | 完全先付け系では役のある側も禁止する解釈があり選択が必要 |
| 副露後に役が成立しない | 和了不可。ドラだけでも和了不可 | 既に役ありで行った副露が後に形を崩した場合の扱いも決定が必要 |
| 門前和了 | 副露順序制限なし。通常の役判定 | 後付け禁止を門前へ適用するか、片和了だけ適用するかの候補がある |
| 喰いタンとの組合せ | 喰いタンは独立にON/OFF可能 | 「なしなし」「ありなし」等を選ぶ必要がある |

**候補と影響**

1. **後付けなし（限定）**: 役のない手で最初の副露をすることだけを禁止し、最初の副露で役が決まった後の待ち・和了牌の条件は別途明示する。第一副露時点の役判定と副露履歴が必要です。
2. **完全先付け（厳格）**: 役のない第一副露を禁じ、どの和了牌でも役が成立することを要求する。第一副露、役確定時点、待ちと全分解の記録が必要です。さらに門前、偶然役だけの和了、役牌同士の双碰、役が後で消えるケース等を決める必要があります。
3. **完全先付けのローカル変種**: 鳴き順、後から役牌をポンしたケース、片和了等を個別に取り決める。仕様ごとに履歴モデル、合法鳴き候補、和了・ロン・CPU判断、オンラインWorker検証、回帰テストの範囲が変わります。

これらを同じ設定名・値にまとめる根拠はありません。HEIBON MAHJONGで採用する後付け禁止の定義は未確定です。ユーザーは今回「未決定のまま設定を保留」と判断しました。機能を実装・公開せず、Issue #17をOpenのままにします。喰いタン対応は独立して実装します。

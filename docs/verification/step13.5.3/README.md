## 設計と縮小条件

- 自分の通常手牌・ツモ牌: 同じグリッド幅から `round(down,100%,1px)` で整数CSS pxに揃え、SVGは60:84。ツモ牌の20% paddingを廃止し、細い区切り線を設けました。全牌に同じmax-width:42pxを適用。副露後も通常牌とツモ牌は同寸法です。
- 卓上牌: 基準18×25.2px、横向きの占有寸法25.2×18px。CSS変数 `--table-tile-width` とその1.4倍の高さを、ドラ、CPU裏面、河、公開副露、加カン重ね牌、槍槓プレビューに共用します。席による回転のみで倍率は変えません。
- 幅: `main`の内容幅をWとして `clamp(13.5px,(W - 24px)/20.6,18px)`。左右のCPU牌列・副露列、左右河、中央情報を同時に収めるため、W < 394.8px（標準余白時の画面幅 < 402.8px）で全卓上牌を一緒に縮小します。320pxでは約0.776倍です。
- 高さ: 高さ650px以下かつ幅599px以下では、通常局面の手牌・44px操作列を見える位置に保つため全卓上牌の幅上限を14px（約0.778倍）にします。中央の最小高さも160→130pxに調整。最大河・最大副露時は縦スクロールを許し、横スクロールは発生しません。
- リーチ牌にも独立縮小を適用せず、河の各セルに回転後の全占有幅を確保。河は6枚×3段を維持します。
- CPU1: 右席の上部に専用ラベル行（最小54px、内容に合わせて拡張）を設け、非公開手牌と副露は次の行へ配置。CPU3は左側に対称配置。親・リーチ・手番・点数を保持し、「リーチ」は語の途中で改行しません。ラベルのabsolute重ね配置は使用しません。

# 河テストモード検証記録

## 起動方法

- Vite開発サーバーでは通常メニューの「河テスト」から開きます。
- GitHub Pagesでは`/heibon-mahjong/test.html?debug=river`を開きます。Pagesは公開環境なので、このURLを知る人は誰でも利用できます。
- 「開始時の自分の河」で枚数を選び、「選択した局面から開始」を押します。初期選択は18枚です。同じ操作で何度でも初期局面へ戻せます。「通常版へ戻る」で通常画面へ戻ります。

## 局面生成

17・18・19枚の開始局面は、固定シードの136枚配牌からゲームの通常の打牌、鳴き、ロン見送り、ツモ処理を順に実行し、自分の手番が打牌待ちになった時点の状態を返します。手牌・河・副露・生きた牌山・王牌は実際のゲーム状態で、物理牌IDを複製しません。

| 開始枚数 | 固定シード | 開始時の生きた牌山 | 打牌後 |
| ---: | ---: | ---: | ---: |
| 17 | 1 | 6 | 18枚 |
| 18 | 276 | 8 | 19枚。CPU3席の後、自分へ手番が戻り20枚目も打牌可能 |
| 19 | 5 | 0 | 20枚。最終ツモ後の打牌となり荒牌へ進行 |

23・24・25枚については、検証時点で打牌待ちの合法局面を固定シードの完全な局進行から確認できませんでした。よってこれらを手作りの状態で補わず、選択肢を無効にしています。これは今回使った固定シード探索での未確認を示し、麻雀ルール上の最大枚数を証明したものではありません。

## 通常対局・オンラインとの分離

局面生成モジュールは`src/verification/`に置き、検証ページだけが読み込みます。通常メニューの項目はVite開発ビルドでのみ表示します。公開URLから検証ページを起動できても、通常の対局状態を置き換えるのは検証ページ内だけです。オンライン対局とCloudflare Workerは使用しません。

## iPhone Safariでの確認手順

1. iPhone Safariで`https://ak-sekine.github.io/heibon-mahjong/test.html?debug=river`を開きます。
2. 初期選択の18枚から開始し、自分の手牌をタップして選択後、「打牌する」を押します。
3. 19枚目が自分の河の4段目に現れ、CPUの打牌後に自分へ手番が戻ることを確認して、20枚目も打牌します。
4. 画面幅に応じて手牌、対面・左右の河、ドラ表示、卓枠の重なりとはみ出しを確認します。17枚・19枚の状態やり直しも同ページで選択できます。
5. 実機の結果は、この記録とは別にユーザー報告後に追記します。

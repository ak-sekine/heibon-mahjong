# オンライン退出通知の配置検証（2026-10-27）

## 原因

退出通知 `#online-exit-notice` は `position: fixed` で `top: max(12px, env(safe-area-inset-top))` に配置されていました。画面上端のセーフエリアだけを考慮し、アプリヘッダーの高さを加えていないため、タイトルとメニューボタンに重なっていました。通知自体はヘッダーより高い `z-index` で描画され、タップ領域も覆っていました。

調査した他の通知は、待機ルームのダイアログ内、オンライン対局のアクション欄内など通常フローに表示されます。画面上に固定する通知は退出通知のみです。

## 修正

- 固定通知の共通クラス `.app-notice` を作り、退出通知に適用しました。
- 上端をセーフエリア、44pxのアプリヘッダー、8pxの間隔の合計より下に配置します。左右もセーフエリアを避け、320px幅でも画面内に収めます。
- ヘッダーのメニューと同じ階層で操作できるよう通知をヘッダーより低い `z-index` にし、通知面の `pointer-events` を無効にしました。
- 通知の文言、退出後の待機状態遷移、8秒の自動消去は変更していません。

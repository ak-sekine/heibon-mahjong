## 全大明カンstress修正（2026-10-17）

### 原因と修正

320×568の卓は320×320px。4面子を一列に並べるルールで各副露箱は約75.81px、合計約303.25pxになる一方、上辺の副露行は左端を牌高基準のx=27.17pxに固定し、折り返しなしだった。このため最終面子がx=330.42pxまで伸び、卓の右端320pxを10.42px越えて右席の手牌と交差し、ルート横overflowを発生させていた。回転した左右席も、同じ一列副露行の長さで卓の縦端を越えていた。

CSSでは4つ目の面子が大明カンまたは暗カンの局面だけ、4辺の副露を各辺内の2列×2段に折り返すようにした。外周の空き帯と辺の席領域を割り当て、左右席の回転基準を牌高分だけ外側へずらした。overflowは隠していない。通常局面の牌寸法・配置と既存の最大密度時89%寸法は変えていない。

修正前の矩形は上辺副露行x=27.17〜330.42px、右席手牌x=294.83〜318.00px、右副露行y=148.17〜451.42px。修正後は同じ320px大明カンstressの要素矩形・重なり・overflow検査を含むStep 13.5.4検証が成功した。全大明カンstressは各家に4つの大明カンと18枚河を同時に置く描画過負荷fixtureで、実牌136枚では成立しない（16個の大明カンに必要な牌だけで64枚を要し、さらに各家18枚の河を別に割り当てる構成）。この物理的不成立はstressの性格を説明するもので、描画検査は維持した。

4つ目の面子がある短い手牌の寸法期待値も、旧Step 13.5.4の42px固定ではなく、通常時と共通のStep 13.5.5寸法を比較する条件に更新した。牌寸法一致と配置検査は引き続き有効で、非公開牌ID検査は変更していない。

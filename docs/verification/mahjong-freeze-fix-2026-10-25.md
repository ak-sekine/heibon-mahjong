# 河の19枚目以降の描画修正（2026-10-25）

調査記録 [mahjong-freeze-investigation-2026-10-25.md](mahjong-freeze-investigation-2026-10-25.md) が示した、描画レイアウトの18枚固定上限を取り除きました。正規の手牌・山の状態は変更せず、河は従来どおり捨て牌の物理牌ID順に描画します。

## 変更

- 1〜18枚の位置を維持し、19〜24枚は6列目までを4段目に配置します。席の向きに応じて上・左の河では外側へ、下・右では従来の並び方向へ延長し、リーチ宣言牌は従来どおり横向きにします。
- 25枚目以降は6枚ごとに5段目以降へ配置し、各段数に合わせて河の領域を広げます。河の物理牌は最大136枚の牌在庫に由来するため、レイアウト関数に18枚や24枚の固定上限を置きません。5段目以降では牌サイズを河の段数に応じて縮め、通常の1〜24枚表示サイズは変えません。
- 鳴きは既存どおり対象牌を表示中の河から除き、履歴へ保持します。今回の変更は表示上の並べ方だけで、捨て牌順・鳴き判定・ルールは変えていません。
- オフライン・オンラインとも同じ河レイアウト関数を使います。描画前に全席の河レイアウトとリーチ宣言牌参照を検証し、レイアウト不正時はDOMを変更する前に診断情報を出して例外を伝播します。打牌済み状態を巻き戻したり、描画例外を握りつぶしたりしません。オフラインは描画前に更新済みの状態で二度目の打牌を受理せず、オンラインは引き続きサーバーのrevision付き状態を正として表示します。
- Browser UI workflowに、ChromiumとWebKitでオンライン・オフライン双方の18〜24枚を320、355、375、390、430px幅で測る検査を加えました。要素の存在だけでなく、卓枠、四河、牌同士、中央表示、ドラ、手牌との矩形重なりとリーチ牌の回転を確認します。

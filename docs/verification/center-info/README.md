# 卓中央の表示改善

対象の開始 main: `a30fa277e50ced07eabe6e2e286bdf4854ba6f52`。
ゲームロジックは変更せず、通常卓とカン検証卓の描画・CSS・SVGを変更。

- 局・本場と山をドラの上の横一行に配置。0本場は省略し、1本場以上だけ表示。
- 王牌の既存の視覚的非表示を維持。供託の文字表示は追加しない。
- 中央領域を左右の河の間の空き幅まで広げ、卓の正方形と河・副露・手牌の配置および牌寸法を維持。
- 供託棒はドラと独立した下段に配置し、既存の表示用両替と0本時の非表示を維持。
- SVGを60:12から60:16に変更し、棒本体の厚みと各額面の点の半径も拡大。

## Chromium 実測

viewport高844px、通常卓、供託1本。旧スタイルの寸法は旧CSSを一時適用して比較。

| 幅 | 旧文字 | 新文字 | 旧点棒CSS枠 | 新点棒CSS枠 |
| --- | --- | --- | --- | --- |
| 320/375/390/430px | 8px | 12px | 18×6px | 36×9.6px |
| 1280px | 11px | 15px | 約28.70×9.56px | 36×9.6px |

旧SVGは中央寄せの余白を含むため、実際のSVG描画範囲はスマートフォンで18×3.6px、1280pxで約28.70×5.74px。
新SVGは枠と同じ縦横比で36×9.6px（ブラウザの丸めで高さ9.59375px）。

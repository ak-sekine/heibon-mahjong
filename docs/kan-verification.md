# カン実機検証ページ

公開先: https://ak-sekine.github.io/heibon-mahjong/kan-test.html

通常画面からのリンクはありません。公開の固定データのみを含みます。
`tests/kan-fixture.ts` は `src/verification/kan-fixture.ts` の再exportです。
局面・準備操作は `tests/browser-step13-5.py` の固定牌山と同じものを使用し、
複数カンでは2枚目の嶺上牌も固定しています。
全牌は単一の136枚の物理牌プールから割り当てます。
通常のGameController、描画、和了判定、得点計算、CPUを使用します。
結果・役・得点の注入や、非公開牌を表示するデバッグUIはありません。

## 操作

シナリオ選択で局面を読み込みます。「固定局面からやり直す」で再試行できます。

| シナリオ | 操作 |
| --- | --- |
| 親の配牌直後の暗カン | 2つの暗カン候補から選択して嶺上ツモを確認。再読込し、カンをキャンセルして通常打牌できることも確認。 |
| 暗カン | カン → 暗カン。嶺上牌を選択 → 打牌する、またはツモ和了。 |
| 大明カン | CPUの東の打牌に対して大明カン。続いて打牌またはツモ和了。「見送る」も操作可能。 |
| 加カン | カン → 加カン。ポンへの追加牌とドラ表示牌を確認。続いて打牌またはツモ和了。 |
| 槍槓 | CPUの加カンを開始 → ロン和了。結果に槍槓1翻。やり直して「見逃す」では加カンが成立し通常進行。 |
| 嶺上開花 | カン → 暗カン → ツモ和了。結果の嶺上開花1翻と得点を確認。 |
| 複数カン | カン → 東または五萬の暗カン。再度カン → 残りの暗カン。ドラ表示牌が3枚になることを確認し、牌を選択して打牌。 |

槍槓の開始ボタンは通常エンジンのdeclareKanを呼びます。
その時点でポンは未確定のままロンの判断を待ち、ロン／見逃しは通常UIで行います。
大明カンの初期状態は通常エンジンでCPUの東を打牌した直後です。
「通常対局に戻る」で通常ページへ移動できます。

## 自動検証

- `npm test`
- `npm run build`
- `npm run dev -- --host 127.0.0.1 --port 4173`
- `python tests/browser-kan-page.py`
- `python tests/browser-step13-5.py`

ブラウザ検証はChromiumの320～1280px幅・タッチ操作で実行します。
既存のSafari向けvisualViewport追従、safe-area、動的viewport対応CSSを共用します。
実際のiPhone Safari上の挙動は公開URLで確認してください。

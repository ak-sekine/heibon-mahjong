## Step 8.3.1：ドラ表示を卓中央へ移動
> **歴史資料:** 以下は整理前READMEのStep記録です。実施当時の仕様・未実装項目・検証結果を示し、現在の仕様を表すものではありません。現在の仕様は [SPEC](../SPEC.md)、実装状況は [ROADMAP](../ROADMAP.md) を参照してください。

iPhone Safariで独立した約139pxのドラ表示エリアが手牌を下へ押し出したため、タイトル下のエリアを削除しました。中央欄に生きた牌山残数・王牌14枚・手番・ドラ表示牌をまとめています。CPU3／CPU2／CPU1の席名を卓上端の3列へ移し、河に卓の全幅を使います。河の牌幅20〜24px、18枚分の予約領域、回転・捨て順は維持しています。

ドラは26×36.4pxの既存SVGを3枠＋2枠の固定2段で表示します。初期公開は従来の1枚だけで、残り4枠は牌面・物理ID・牌種を持たない空要素とCSS疑似要素です。表示枚数が増えてもグリッドの幅・高さ、卓、手牌、操作欄の座標は変わりません。中央では牌面を優先し、表示牌番号と対応するドラ牌種の文字は読み上げ用に保持します。通常ドラ・赤ドラ計算、役・和了判定、公開位置とCPU進行は変更していません。カン・追加ドラ公開・裏ドラ・CPU和了・ロン・点数計算は追加していません。

手牌14枚の横1行、44px操作ボタン、sticky操作欄、`100svh`、viewport-fitとSafariセーフエリア対応を維持しています。320px幅では説明文字と操作欄の余白を縮め、キーボード操作の補助文を非表示にします（キーボード操作自体は維持）。高さを120px減らした画面では必要に応じて文書を縦スクロールして操作できます。

検証コマンド（2026-10-12）：

```sh
npm test
node --test --test-isolation=none tests/*.test.ts
npm run build
npm run dev -- --host 0.0.0.0 --port 4173
python tests/dora-layout-check.py
python tests/browser-check.py --tsumo-fixture --screenshots /tmp/heibon-gameplay
```

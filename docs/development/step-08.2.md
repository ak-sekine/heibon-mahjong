## Step 8.2：ドラ表示牌と通常ドラ
> **歴史資料:** 以下は整理前READMEのStep記録です。実施当時の仕様・未実装項目・検証結果を示し、現在の仕様を表すものではありません。現在の仕様は [SPEC](../SPEC.md)、実装状況は [ROADMAP](../ROADMAP.md) を参照してください。

王牌は既存の14枚をそのまま使い、`src/game/dora.ts`の`exposedDoraIndicators(wall)`が`deadWall[4]`への参照1枚を配列で返します。別の物理牌の生成・複製や追加ツモはなく、生牌山や王牌から取り除きません。位置は`DORA_INDICATOR_INDICES = [4, 6, 8, 10, 12]`に集約しています。

| 0始まりの王牌インデックス | 論理用途 |
| --- | --- |
| 0〜3 | 将来の嶺上牌（未使用） |
| 4 | 最初のドラ表示牌。今回唯一公開する牌 |
| 5 | 最初の裏ドラ表示牌（非公開） |
| 6・8・10・12 | 将来の追加ドラ表示牌（非公開） |
| 7・9・11・13 | 対応する裏ドラ表示牌（非公開） |

物理的な積み方・向きは再現せず、この配列位置を論理的な約束として使います。ドラ表示牌は配牌直後から公開し、通常ツモ・打牌・牌山終了・ツモ和了後にも同じ物理IDのまま保持します。他の王牌13枚とCPU手牌はDOMに描画しません。状態にドラ情報を重複保存しないため、「新しい対局」では新しくシャッフルした王牌から自動的に決まり、以前の情報を引き継ぎません。同じ牌面が偶然続くことはあります。既存のAbortController・世代番号によるCPU処理の中止を維持しています。

`src/analysis/dora.ts`の純粋API：

- `doraKindFromIndicator(indicator: Tile): TileKind`：表示牌の次の牌種。赤属性や物理IDを含まない。
- `countDora(tiles: readonly Tile[], indicators: readonly Tile[]): number`：各表示牌について手牌内のドラ牌種の枚数を数え、その合計を返す。
- `countRedDora(tiles)`：既存仕様のまま、手牌内の赤5だけを独立して数える。

数牌は萬・筒・索ごとに1→2→…→9→1、風牌は東→南→西→北→東、三元牌は白→發→中→白と循環します。風牌と三元牌は混ぜません。赤5表示でもドラは同色の6です。表示牌が赤牌でも手牌外の牌なので赤ドラ加算はありません。

4萬表示なら5萬と赤5萬の両方が通常ドラです。赤5萬1枚は通常ドラ1翻＋赤ドラ1翻、通常5萬1枚＋赤5萬1枚は通常ドラ2翻＋赤ドラ1翻になります。他の色の赤5はこの通常ドラに数えません。正常な0枚は0を返します。未知の牌種・不正な赤属性・同色の赤5複数枚・配列以外は`RangeError`で拒否し、入力牌や配列を変更しません。14枚・各種4枚以下・物理IDの整合性は既存の和了処理側で検証します。

表示牌の配列は公開された各位置を1回ずつ渡す契約です。牌面APIは物理IDを持たないため、同じ牌面の別表示牌を除外しません。将来複数の表示牌が同じドラ牌種を指す場合は表示牌枚数分を加算できます。今回はヘルパーが位置4のみを一度返し、追加表示牌の公開は実装していません。

`TsumoResult`には`doraCount`（完成手牌14枚の通常ドラ枚数）と`doraHan`（通常ドラの加算翻数）を追加しています。`totalHan`と`yakuHan`は従来どおり選択されたStep 7候補の成立役翻数です。通常和了では`totalHanIncludingDora = yakuHan + doraHan + redDoraHan`。役2翻・通常ドラ1翻・赤ドラ2翻なら5翻です。役満では枚数を情報として保持しても`doraHan`・`redDoraHan`・`totalHanIncludingDora`を0にし、画面は役満数だけを表示します。役満を通常翻に換算しません。

ドラと赤ドラは役ではありません。Step 6の形判定、Step 7の`YakuId`・役一覧・`hasSupportedYaku`は変更せず、ドラだけで和了可能にはしません。候補は既存の役満数→成立役翻数→候補IDの順で選び、異なる候補の役を合算しません。結果画面は役一覧、役合計、通常ドラ枚数・翻数、赤ドラ枚数・翻数、ドラ込み合計を分離し、0枚も表示します。「点数計算は未実装です。」を維持します。

Step 8.2時点では、320px幅で中央文字を8px・余白を2pxに縮小して初期表示牌が操作欄に隠れないようにします。卓上中央の情報欄で、牌山残数・王牌14枚・手番の下に「ドラ表示牌」、幅24pxの既存SVGの牌面、「ドラ：計算した牌名」を縦に表示します。SVGの`aria-label`で牌名を読み上げられます。表示は操作ボタンではなく、タップしても状態は変わりません。結果画面に牌面を重複表示せず、卓上表示を継続します。手牌14枚の1行配置、河の回転と順序、44px操作ボタン、sticky操作領域、svhとSafariセーフエリアを維持し、必要な縦スクロールを許容します。

# Step 13.6：一般役4種類の追加

実施日：2026-10-18

## 対象と採用ルール

このステップの実装範囲は、三色同順・一気通貫・混一色・清一色です。翻数は次のとおりです。

| 役 | 門前 | 副露 |
| --- | ---: | ---: |
| 三色同順 | 2翻 | 1翻 |
| 一気通貫 | 2翻 | 1翻 |
| 混一色 | 3翻 | 2翻 |
| 清一色 | 6翻 | 5翻 |

三色同順・一気通貫は、同一の標準和了分解に含まれる順子面子で判定します。確定済みのチーも含め、三色同順は3色で同じ開始数字、一気通貫は同色の開始数字1・4・7を確認します。各役は分解ごとに最大1回です。

混一色・清一色は手牌と確定済み副露の牌種をまとめて判定します。混一色には1種類の数牌と1枚以上の字牌が必要です。清一色には1種類の数牌だけが必要です。字牌だけの手は混一色にならず、清一色が成立すると混一色は加えません。両役は七対子と複合します。赤5は同じ色の通常5として扱い、赤ドラは既存処理で別加算します。

暗カンのみなら門前を維持します。チー・ポン・大明カン・加カンがあれば副露扱いです。カンは1面子として和了形に渡します。

## 主な実装内容

- `YakuId` と通常役翻数の型に4役、および3・5・6翻を追加しました。役満は翻数と分けた既存表現を維持しています。
- `StandardDecomposition` の面子から順子の開始牌を集め、三色同順・一気通貫を分解単位で判定します。
- 手牌と確定済み副露から色を集計し、混一色・清一色を標準形・七対子の共通候補へ加えます。
- 固定順子の色役誤判定を防ぐため、確定面子の牌構成を和了形解析で検証します。
- 既存の `evaluateWin`、候補の点数最大選択、符・点数計算、局精算を再利用しました。点数式、ドラ処理、UIレイアウト、牌サイズ、卓CSSは変更していません。
- 局結果概要と詳細結果に正式役名を追加しました。概要は既存どおり役名と総翻数を表示し、詳細は役ごとの翻数を表示します。

## 既存実装との整合

新役は既存の共通和了経路を通るため、人間・CPUのロン/ツモ、副露後の和了、複数ロン、カン後の和了で同じ候補評価と点数計算を使います。役翻と通常ドラ・裏ドラ・赤ドラは別に保持します。清一色の門前6翻・副露5翻は既存の満貫以上の上限計算へ渡します。役満候補には一般役を加算しません。

# Heibon Mahjong

Heibon Mahjong は、CPU 3人と遊ぶ日本式リーチ麻雀のブラウザーゲームです。TypeScript と Vite で開発し、GitHub Pages で公開しています。

**公開版:** [https://ak-sekine.github.io/heibon-mahjong/](https://ak-sekine.github.io/heibon-mahjong/)

## ゲームの特徴

- 4人打ちの東風戦。初期持ち点は各25,000点で、局の精算と最終順位まで対局できます。
- 手牌を選んで打牌し、CPU 3人は自動で進行します。スマートフォンとデスクトップに対応した卓を表示します。
- ツモ・ロン、フリテン、リーチ・ダブル立直・一発、ポン・チー、暗カン・大明カン・加カンに対応しています。
- 対応役、符・点数、ドラ・裏ドラ・赤ドラ、局結果を表示します。
- カン機能の公開検証ページ: [kan-test.html](https://ak-sekine.github.io/heibon-mahjong/kan-test.html)。
- オフライン検証シナリオのページ: [test.html](https://ak-sekine.github.io/heibon-mahjong/test.html)。

## 現在実装されている主な機能

- 136枚の牌を使った配牌、東場の局進行、親の連荘、持ち点・本場・供託の精算。
- 通常形・七対子・国士無双の和了形判定と、実装済み役による和了判定。
- 和了牌のロン判定、複数ロン、捨て牌・一時・立直後のフリテン。
- 立直後のツモ切り、リーチ成立・ダブル立直・一発、裏ドラ。
- ポン・チーと喰い替え制限、暗カン・大明カン・加カン、槍槓・嶺上開花。
- 通常流局と四開槓による途中流局。
- CPUの向聴数・有効牌を使った打牌、基本的な鳴き・立直・カン判断。
- 対局中のCPU手牌など、公開されていない牌情報を画面のDOMへ出さない表示。

現在のルールと、実装済み・未対応の役や流局の一覧は[ゲーム仕様](docs/SPEC.md)を参照してください。ここに書かれていない機能を含む詳細は、ソースを確認してください。

## 対局と操作の概要

画面右上の三本線メニューから「新しい対局」「オンライン待機」を開けます。オンライン参加中は「ルーム操作」も同じメニューに表示されます。

1. 新しい対局を開始すると、東1局の配牌が行われます。親は配牌の追加牌を持って打牌します。
2. ユーザーの手番では、手牌またはツモ牌を選び、「打牌する」で確定します。選んだ牌をもう一度選ぶと選択を解除できます。
3. CPUの手番では自動でツモ・和了判断・打牌が進みます。進行中はユーザーの打牌操作を受け付けません。
4. ロンや鳴きなどの選択がある場合は、打牌操作欄に判断ボタンを表示します。カンは合法候補から面子を選んで実行します。
5. 局が終わると結果を確認でき、東風戦が続く場合は「次の局へ」進みます。対局終了後は結果画面から新しい対局を始められます。

Tabで操作対象へ移動し、EnterまたはSpaceで選択・確定できます。役・得点や局進行の詳細条件は[SPEC.md](docs/SPEC.md)にまとめています。

## 技術構成

| 領域 | 使用技術・役割 |
| --- | --- |
| 言語 | TypeScript |
| 開発・ビルド | Vite、Node.js 24 |
| 公開 | GitHub Pages |
| `src/model/` | 牌、プレイヤー、ゲーム・対局状態の型 |
| `src/game/` | 配牌、進行、鳴き、和了、CPU判断、精算 |
| `src/analysis/` | 和了形、役、向聴数、符、点数、ドラ判定 |
| `src/ui/`・`src/rendering/` | 操作状態とSVGを使った画面表示 |
| `tests/` | 自動テストと必要時に実行するブラウザー検証 |

ゲーム状態の処理は描画やDOM操作から分離しています。画面を調整するときも、ゲームルールと牌の物理ID管理を保つ方針です。

## ローカルで起動する

Node.js 24 を使用します。

```sh
npm ci
npm run dev
```

Vite が表示するローカル URL をブラウザーで開きます。開発用の全牌一覧は卓の下にあります。

## テストとビルド

```sh
npm test
npm run build
```

`npm test` は Node.js の自動テスト、`npm run build` は TypeScript の型検査と Vite の本番ビルドを実行します。プレビューする場合は `npm run preview` を使います。

ブラウザー検証は開発・検証タスクで必要な場合に実施します。過去の実行ログと画面資料は[検証記録](docs/verification/README.md)と[スクリーンショット](docs/screenshots/)にあります。文書だけを変更する作業では、ゲームのテストやビルドを繰り返す必要はありません。

## ブラウザー検証ページ

[カン検証ページ](https://ak-sekine.github.io/heibon-mahjong/kan-test.html)は、通常対局と分けた公開確認用ページです。次のシナリオを選べます。

- 暗カン
- 大明カン
- 加カン
- 槍槓
- 嶺上開花
- 複数カン

[テスト環境](https://ak-sekine.github.io/heibon-mahjong/test.html)では、九種九牌（自分／CPU1／CPU2／CPU3）を確認できます。シナリオを選び「テスト開始」を押してください。「同じシナリオを再実行」で同じ局面を再生成できます。CPUケースは既存のCPU自動処理で宣言し、自分のケースは卓の「九種九牌」ボタンで宣言します。ページは公開アクセス可能なため、個人情報や認証情報を入力しないでください。

自動テストやChromiumの検証と、iPhone Safari実機での確認は区別して記録します。2026年10月18日のユーザーによる実機確認は[検証記録](docs/verification/kan-safari-2026-10-18.md)にあります。

# Quill Mahjong

日本式リーチ麻雀のStep 4。自分（プレイヤー0）を親に固定し、配牌直後の14枚から1枚を選んで打牌し、自分の河へ表向きで表示できます。最初の打牌で停止し、CPU打牌、次のターン、追加のツモは実行しません。

## 操作と画面

4人卓を維持しています。0は下（自分）、1は右、2は上、3は左（CPU）です。自分の13枚は牌種順、追加牌は右端に間隔を空けて表示します。CPUは各13枚の裏向き牌のみを描画し、牌面と物理牌IDをDOMへ出しません。

牌をタップすると物理牌IDで選択し、8px上へ移動、背景と枠、選択牌名、`aria-pressed`で通知します。別の牌で選択変更、同じ牌で解除できます。選択だけではGameStateを変更しません。「打牌する」（44px以上の高さ）で確定し、未選択時と打牌後は無効です。Tabで牌／ボタンへ移動し、Enter／Spaceで選択・確定できます。細い手牌のタッチ領域は重ねず、選択牌名とキーボード操作を補助にしています。

打牌後は手牌13枚、追加牌なし、自分の河1枚、CPU各13枚・河0枚、生きた牌山69枚・王牌14枚です。追加牌の空き枠は残しません。「打牌完了（次のターン処理は未実装）」を表示します。河には既存SVGを使い、赤5状態と`data-tile-id`を維持します。各河は捨てた順に複数枚を描画できる構造です。

「新しい対局」は`startGame()`で再配牌し、4人の手牌・追加牌・河・打牌待ち状態・選択を初期化します。開発用牌一覧は既存のままです。

## 状態と打牌処理

`PlayerState.river`は順序付きの`readonly PhysicalTile[]`です。4人それぞれ独立した空配列で開始します。`GameState.turnPlayerId`は配牌時の親、`phase`は`awaiting-discard`（打牌待ち）または`stopped`（後続未実装）です。

`src/game/discard.ts`の`discardFromPlayer()`はDOMに依存しない純粋関数で、CPUでも共用できる牌移動を担当します。

- 追加牌を捨てる：13枚のhandを維持し、drawnTileをriver末尾へ移動してnullにします。
- handから捨てる：指定IDだけを除去し、drawnTileをhandへ追加してnullにします。捨てた牌はriver末尾へ移動します。描画時に手牌をソートします。

`discardTile(game, playerId, tileId)`は現在の操作制限を担当し、新しいGameStateを返してphaseをstoppedにします。自分が親かつ打牌待ち・自分の順番であること、13枚＋追加牌を持ち未打牌であることを要求します。不明ID、他領域の牌、CPU、親でない／順番でない操作、打牌後／打牌不可状態はRangeErrorで拒否します。元の状態・配列・PhysicalTileは変更しません。既存の物理牌を移動するのでIDと赤5を保存します。

`src/ui/controller.ts`で最新のGameStateと独立した選択IDを保持し、`src/main.ts`が操作と描画を接続します。確定は状態を更新してから描画し、連打でも2枚目は捨てません。`src/rendering/table.ts`は手牌・河・席・中央情報・選択表示を担当します。牌山生成・シャッフル・配牌、60:84のSVGデザインは維持しています。

## 開発・検証

Node.js 24を使用します。実行時・npm依存ライブラリの追加はありません。

```sh
npm ci
npm test
npm run build
npm run dev
```

自動テスト17件：既存の牌／牌山／配牌／4人卓に加え、両方の打牌、赤5、同牌種のID区別、136枚・全34牌種各4枚・ID重複なし、凍結した元状態の不変性、不正操作、2回目拒否、共通CPU牌移動、選択切替／解除、無選択、確定後とリセット、DOMの河表示とCPU情報非公開を確認します。

Chromiumで320×568、375×667、390×844、1280×800を確認済みです。全サイズで追加牌／手牌からの打牌、キーボード操作、連打防止、新しい対局、14枚1行、横スクロールなし、選択牌と席表示／河の非重複、河と中央情報の非重複、CPU3人・空の河を検証しました。スクリーンショットも確認しています。

再実行用の任意のブラウザ検証は、Python PlaywrightとChromiumがある環境で以下を実行します（npm testやアプリの依存には含みません）。

```sh
npm run preview -- --host 0.0.0.0
# 別ターミナル
python tests/browser-check.py
```

`--url`と`--screenshots`で対象URLと画像出力先を指定できます。
